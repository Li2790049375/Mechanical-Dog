# Mechanical Dog — 基于 ESP32 的四足仿生机器狗

一个基于 ESP32 双核微控制器的四足仿生机器狗项目，支持远程网页控制和串口指令控制，具备多步态行走、IMU 自平衡、摄像头实时图传等功能。

## 硬件组成

| 模块       | 型号/芯片        | 通信接口        | 说明                                                      |
| ---------- | ---------------- | --------------- | --------------------------------------------------------- |
| 主控       | ESP32            | —               | 双核 FreeRTOS，Core 0 处理串口指令，Core 1 处理步态与外设 |
| 舵机驱动   | PCA9685 (0x40)   | I2C             | 16 路 PWM，50Hz，实际使用 12 路（4 腿 × 3 舵机/腿）       |
| IMU        | ICM20948 (0x68)  | I2C             | 九轴传感器，用于姿态检测与自平衡                          |
| 电流传感器 | INA219 (0x42)    | I2C             | 电池电压、电流、功率监测                                  |
| 显示屏     | SSD1306 128×32   | 软件 I2C        | 实时显示当前状态、电压、WiFi 信息                         |
| RGB LED    | WS2812 × 2       | 单总线 (GPIO26) | 不同颜色指示不同运动/功能状态                             |
| 摄像头     | ESP-EYE (OV2640) | 8位并行         | MJPEG 视频流，QVGA 分辨率                                 |
| 蜂鸣器     | 有源蜂鸣器       | GPIO21          | 运动指令反馈                                              |

**I2C 引脚**：SDA=GPIO32, SCL=GPIO33

## 软件架构

```
main.cpp          # 入口: 初始化 → 主循环
├── robot_motion.h # 运动学核心: IK解算、步态生成、动作函数、自平衡
├── web_server.cpp # WiFi + HTTP服务: AP/STA、摄像头推流、控制接口
├── InitConfig.h   # 外设初始化: IMU/INA219/OLED/RGB/蜂鸣器
├── PreferencesConfig.h # NVS存储: 舵机校准值持久化
└── WebPage.h      # 网页控制界面 (HTML/CSS/JS 内嵌)
```

## 运动学

### 腿部结构

每条腿由 3 个舵机驱动，基于五连杆机构：

- **摆动舵机**：控制腿部在 XZ 平面的内外摆动
- **前连杆舵机** + **后连杆舵机**：共同控制腿部在 XY 平面的位置（类似平行四连杆）

连杆尺寸（mm）：`A=40, B=40, C≈39.82, D≈31.78, E≈30.81, W=19.15, S=12.2`

### 逆运动学解算链

```
wigglePlaneIK()          → 摆动平面 IK，输入 Y/Z 位置，输出摆动角和等效长度
    ↓
singleLegPlaneIK()       → 单腿平面 IK，输入 X/等效长度，输出连杆角度和足端 XY
    ↓
simpleLinkageIK()        → 五连杆 IK，输出前/后/摆动舵机角度
    ↓
goalPWMSet()             → 角度转 PWM 脉宽
```

### 步态

- **对角步态 (Trot)**：对角腿成对摆动（腿1+3 一组，腿2+4 一组），相位差 0.5 周期
- **三角步态**：四条腿按 0.25 周期相位依次摆动，带重心动态调整，更稳定

步态参数可调：行走高度、抬腿高度、步幅、加速度区间、抬腿占比等。

## 控制方式

### 1. 网页远程控制

设备启动后默认开启 WiFi 热点：

- **SSID**: `LH666`
- **密码**: `LH123456`

浏览器访问设备 IP（默认 `192.168.4.1`），可进行：

- **方向控制**：前进/后退/左转/右转（支持 8 方向组合）
- **功能动作**：平衡、趴下起立、握手、跳跃、点头、打招呼、旋转、蹲下、趴平
- **舵机调试**：16 路舵机逐路微调 + 保存校准值
- **视频推流**：MJPEG 实时画面（端口 81，`/stream`）

网页界面带 GSAP 动画效果和粒子背景。

### 2. 串口 JSON 指令

通过串口（115200 bps）发送 JSON 指令：

```json
{"var": "move", "val": 1}      // 运动控制: 1前 2左 3前后停 4右 5后 6左右停
{"var": "funcMode", "val": 2}  // 功能模式: 1平衡 2趴下 3握手 4跳跃 5点头 6打招呼 7旋转 8初始位 9中间位 10蹲下 11趴平
{"var": "ges", "val": 1}       // 姿态调整: 1上仰 2下俯 3俯仰归零 4左偏航 5右偏航 6偏航归零
{"var": "light", "val": 1}     // 灯光: 0~7 不同颜色
{"var": "buzzer", "val": 0}    // 蜂鸣器: 0关 1开
```

设备定时通过串口上报电池电压：

```json
{"vol": 7.4}
```

### 3. 有线调试模式

GPIO12 接高电平时进入舵机调试模式，可用于初始装配时的舵机校准。

## 功能动作列表

| funcMode | 动作     | 说明                                 |
| -------- | -------- | ------------------------------------ |
| 1        | 自平衡   | IMU PD 控制，实时调整俯仰/横滚姿态   |
| 2        | 趴下再起 | 先蹲到最低，再伸到最高，最后回站立位 |
| 3        | 握手     | 右前腿抬起做上下握手动作             |
| 4        | 跳跃     | 四腿下蹲后瞬间伸展跳起               |
| 5        | 点头     | 前腿下沉三次模拟点头                 |
| 6        | 打招呼   | 左前腿抬起做招手动作                 |
| 7        | 旋转     | 对角步态原地旋转                     |
| 8        | 初始位置 | 所有舵机复位到 MiddlePosition        |
| 9        | 中间位置 | 所有舵机复位到存储的校准中间值       |
| 10       | 蹲下     | 前腿蹲低后腿撑高                     |
| 11       | 趴平     | 四腿向外伸展趴下                     |

## OLED 状态显示

屏幕两行显示：

- **第 1 行**：当前状态（待机 / 前进 / 后退 / 左转 / 右转 / BALANCE / JUMP / NOD 等）
- **第 2 行**：电池电压 + WiFi 模式（AP / STA 信号强度）

启动时播放火柴人打招呼动画和署名信息。

## 开发环境

- **IDE**：VS Code + PlatformIO
- **平台**：`espressif32@3.5.0`
- **开发板**：`esp32dev`
- **框架**：Arduino

### 编译与烧录

```bash
# 安装 PlatformIO CLI 后
cd "Mechanical Dog"
pio run              # 编译
pio run -t upload    # 烧录
```

## 注意事项

1. 首次上电前需通过调试模式（IO12 拉高）或网页 PWM 调整页面校准每个舵机的中间位置
2. 舵机校准值保存在 NVS 分区（`ServoConfig` 命名空间），掉电不丢失
3. 自平衡功能依赖 IMU 处于水平安装姿态
4. 步态参数（高度、步幅、速度等）在 `robot_motion.h` 顶部宏定义中调整
5. WiFi 默认开启 AP 模式；如需连接路由器，修改 `web_server.cpp` 中 `DEFAULT_WIFI_MODE` 为 2 并配置 `STA_SSID` 和 `STA_PWD`
